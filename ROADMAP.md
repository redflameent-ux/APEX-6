# APEX-6 roadmap

Goal: a full rig in the class of Guitar Rig, AmpliTube, Helix and Metallurgy.

## Round 2 - the rack grows up
- Use the same unit more than once (two drives, two delays...)
- Split / parallel paths (A/B split, crossover split, mixer) like Helix
- Built-in tuner (big strobe view) and a looper
- Input/output meters on every unit, global noise reduction

## Round 3 - more amps
- More amp heads, each with its own voicing: clean American, British crunch, high-gain modern,
  djent/"metallurgy"-style tight, bass amp, a dark doom amp
- Power-amp options (tube types, sag), amp "boost" switch, bright switch
- Mic placement for the built-in cabs, IR browser with folders and favourites

## Round 4 - pedal board
- Drives: tube-screamer style, klon style, rat style, big muff style, octave fuzz
- Mod: chorus, flanger, phaser, tremolo, vibe, rotary
- Pitch: octaver, whammy, harmonizer, detune
- Filters: wah (auto + MIDI), envelope filter, talk-box style formant
- More Safari-style oddballs: granular freeze, ring mod, pitch-drop glitch, radio, lo-fi sampler

## Round 5 - studio finish
- Multi-band compressor, graphic + parametric EQ, transient shaper, limiter
- Macros (one knob moves many), MIDI learn, footswitch / preset switching
- Big preset library: metal, djent, dub/reggae, ambient, industrial, Memphis, sacred/world
- Doubler / quad-tracking for wide metal rhythms
